2Tools & Platforms I Used

What each tool is, and why it earned a place in my workflow.

VS Code

Code Editor

What: A free, lightweight code editor with extensions.

Why: One editor for C, C++, Python and web projects.

Git

Version Control

What: A version control system that records every change.

Why: To save progress, undo mistakes and push work to GitHub.

GitLens

Extension

What: A VS Code extension that shows who changed which line, and when.

Why: To read commit history while practising teamwork.

GCC

Compiler

What: The GNU C compiler.

Why: To compile my C programs from the terminal, for example:

$ gcc line_editor.c -o line_editor

Line Editor

C Project

What: A command-line text editor I built in C with my team. It inserts, deletes, displays, saves and loads lines, using an array of strings.

Why: To practise data structures and file handling.

4Portfolio Building

Steps to create and host my portfolio website on Vercel.

1
Plan the story
Who I am, what I know, what I built, my certificates, my GitHub, contact.
2
Build the site
React, TypeScript, Tailwind CSS and Vite, with Framer Motion for animation.
3
Add personality
MUBA AI, a voice-first assistant that answers questions about my portfolio.
4
Test locally
Run npm install, then npm run dev, then npm run build to create dist/.
5
Push to GitHub
Commit with Git. Keep API keys in environment variables, never in the repo.
6
Deploy on Vercel
Import the GitHub repo, and every push goes live automatically.
