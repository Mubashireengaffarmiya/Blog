## ✨ Features

- **Developer Journey Sections**: Chronological progression through About Me, Tools & Platforms, Coding Practice, Portfolio Building, Collaboration, Social Presence, Achievements, and Future Goals.
- **Dark & Light Mode Support**: Seamless toggle between light and dark themes with system preference detection (`prefers-color-scheme`) and persistent `localStorage` memory.
- **Responsive Design**: Flawless layout across mobile devices, tablets, laptops, and ultra-wide desktop monitors without horizontal overflow.
- **Interactive Sticky Navigation**: Fast navigation with mobile drawer support and active section detection via `IntersectionObserver`.
- **HackerRank Algorithm Portfolio**: Responsive table showcasing 3rd-semester algorithms, time complexities, and key takeaways.
- **Visual CI/CD Pipeline**: Step-by-step portfolio architecture roadmap from local development to Vercel deployment.
- **Accessibility & Performance**: Built with semantic HTML5 elements, ARIA labels, zero external network dependencies, and lightning-fast local rendering.
- **Pure Static Architecture**: 100% self-contained with no external CSS/JS CDN dependencies or build steps required.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<footer>`).
- **CSS3**: Modern layout system utilizing CSS Variables, Flexbox, Responsive CSS Grid, Media Queries, and Glassmorphism accents.
- **Vanilla JavaScript**: Lightweight (~50 lines) zero-dependency script for theme switching, mobile drawer control, active scroll tracking, and smooth navigation.

*(Note: The portfolio project referenced within the journey was built using React, TypeScript, Tailwind CSS, and Vite. This blog website itself is cleanly authored in pure, standards-compliant static HTML5, CSS3, and vanilla JavaScript).*

## 💻 How to Run Locally

You can view this website without installing Node.js, npm, or any package managers.

### Option 1: Open Directly in Browser
Double-click `index.html` or open it with your web browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Option 2: Run with a Local Static Server (Python)
If you prefer running via a local web server:
```bash
python -m http.server 8000
```
Then navigate to:
```
http://localhost:8000
```

## 📤 GitHub Upload Instructions

To publish this project to your GitHub account under the repository name `portfolio-journey-blog`, run the following commands in the project directory:

```bash
# 1. Initialize git repository
git init

# 2. Stage all files
git add .

# 3. Create initial commit
git commit -m "Add portfolio journey blog"

# 4. Set branch to main
git branch -M main

# 5. Connect remote repository
git remote add origin https://github.com/Mubashireengaffarmiya/portfolio-journey-blog.git

# 6. Push code to GitHub
git push -u origin main
```

## 🌐 Deployment to GitHub Pages

You can host this website for free using **GitHub Pages**:
1. Push your code to GitHub following the steps above.
2. In your GitHub repository, navigate to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)` folder.
4. Click **Save**.
5. Your website will be live in minutes at:  
   `https://mubashireengaffarmiya.github.io/portfolio-journey-blog/`

Alternatively, you can drag and drop this repository into [Vercel](https://vercel.com/) or [Netlify](https://www.netlify.com/) for instant deployment.
